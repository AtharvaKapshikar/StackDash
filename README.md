# 📊 StackDash – Scalable Admin Dashboard

StackDash is a full-stack admin dashboard built to showcase scalable architecture, polished UI/UX, and robust backend integration. Designed as a portfolio centerpiece, it demonstrates production-ready features for SaaS platforms, internal tools, and enterprise dashboards.

---

## 🛠 Tech Stack

- **Frontend**: Angular 16+, TypeScript, SCSS
- **Backend**: Java 8+, Spring Boot, Hibernate
- **Database**: Oracle SQL
- **Testing & Tools**: Postman, JUnit, Mockito

---

## ✨ Features

- 🔐 **Role-Based Login**: Secure token propagation and CORS handling
- 📋 **Paginated Task Management**: Native SQL queries with DTO mapping
- 🔔 **Notification System**: Smooth popups and subtle animations
- 📱 **Responsive UI**: Mobile-friendly layout with polished CSS
- 🧠 **Scalable Architecture**: Null-safe updates, reusable mappers, and clean separation of concerns
